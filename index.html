02 / ABSTRACT

초록

음악을 만드는 기술이 보편화될수록,
창작의 주도권을 다시 묻습니다.

Sovereign Music Lab은 음악가의 지식, 로컬 AI, 인간의 연주를 하나의 창작 과정으로 연결하는 프로젝트입니다. 음악 이론 자료를 검색하는 RAG, 검토된 예제로 모델을 조정하는 LoRA, 편집 가능한 MIDI와 Logic Pro 작업 흐름을 함께 탐구합니다.

우리가 지향하는 소버린 음악은 자신의 자료와 도구, 창작 과정을 직접 관리할 수 있는 음악입니다. AI가 제안한 음표는 완성의 시작점입니다. 사람이 고르고, 고치고, 호흡과 강약을 더하며 자신의 연주로 작품을 완성합니다.

01

PHILOSOPHY

음악의 주도권은
만드는 사람에게.

작곡가는 결과물뿐 아니라 그 결과에 도달하는 과정도 다룰 수 있어야 합니다. 어떤 자료를 참고했는지, 어떤 모델을 썼는지, 어느 음표를 바꿨는지 확인하고 선택할 수 있는 환경을 만듭니다.

개인에게는 자신만의 작곡 작업실을, 개발자에게는 확장할 수 있는 도구를, 음악가에게는 해석하고 연주할 수 있는 재료를 제공합니다. 이 세 가지 방향이 하나의 연구실 안에서 만납니다.

01 / OWN YOUR PROCESS

과정을 보유합니다

작곡 요청, 참고 근거, 음표와 수정 기록을 로컬 작업 공간에 남깁니다.

02 / KEEP IT EDITABLE

수정할 여지를 남깁니다

MIDI 음표와 페달 데이터를 보존해 사람이 직접 편곡하고 해석합니다.

03 / PLAY IT YOUR WAY

연주로 완성합니다

같은 음표에서도 다른 호흡과 시간이 생깁니다. 마지막 선택은 연주자의 몫입니다.

02

THE CREATIVE LOOP

지식은 음표가 되고,
음표는 연주가 됩니다.

검색과 학습, 작곡과 연주는 서로 다른 역할을 맡습니다. 각 단계를 구분하고 검토하며, 사람의 피드백이 다음 실험의 출발점이 되도록 설계합니다.

  1. 01

    Knowledge

    인간이 쌓은 지식

    사용자가 보유한 자료에서 필요한 음악 이론과 근거를 검색합니다.

    RAG · OPTIONAL
  2. 02

    Intelligence

    로컬 모델의 제안

    모델이 음표를 구성합니다. LoRA는 별도로 검토한 예제를 통한 추가 학습입니다.

    LOCAL LLM + LoRA
  3. 03

    Composition

    편집 가능한 음악

    음표·박자·일부 화성 조건을 검사하고, MIDI를 Logic으로 전달합니다.

    MIDI → LOGIC PRO
  4. 04

    Performance

    사람의 해석과 연주

    직접 고치고 연주합니다. 평가는 기록하며, 다음 학습에는 별도 검토를 거칩니다.

03

MEET THE TOOLKIT

A SOVEREIGN MUSIC LAB PROJECT

DeepChord.

로컬 AI의 첫 음표를,
나의 음악으로.

DeepChord 저장소 ↗설치 안내 ↓

DeepChord는 개인의 음악 지식과 로컬 언어 모델을 연결하는 피아노 작곡 도구입니다. 자연어로 요청한 스케치를 음표 데이터로 만들고, 검증을 거쳐 편집 가능한 MIDI로 내보냅니다.

RAG는 자신의 자료에서 근거를 찾고, LoRA는 검토한 예제로 모델을 조정합니다. 두 기능은 선택 사항이며, 생성한 음악은 Logic Pro에서 고치고 연주하며 완성합니다.

PYTHON 3.11+APACHE 2.0LOCAL-FIRST
  1. RAG · LoRA개인의 지식과 학습
  2. Local LLM1–16마디 피아노 스케치
  3. Editable MIDI음표·박자 검증과 출력
  4. Logic Pro + MCP사람의 편집과 연주

현재 Logic 연결은 MIDI 파일 열기와 선택적 MCP 상태 확인을 지원합니다. 악기 선택, 프로젝트 저장, 최종 연주는 사용자가 진행합니다.

04

FROM INSTALL TO FIRST NOTES

설치하고,
첫 음악을 만들어 보세요.

아래 명령을 터미널에서 순서대로 실행하세요. Git과 Python 3.11 이상이 필요합니다. 명령 예시는 macOS의 zsh/bash 기준입니다.

Logic 연결: macOS + Logic Pro · LoRA 학습: Apple Silicon Mac
기본 설치 확인에는 모델이나 음악 교재가 필요하지 않습니다.

  1. STEP 01

    내 컴퓨터에 설치

    저장소를 내려받아 가상 환경에 설치합니다. 이후 명령도 이 환경이 활성화된 터미널에서 실행하세요.

    TERMINAL · INSTALL
    git clone https://github.com/Sovereign-Music-Lab/DeepChord.git
cd DeepChord
python3 -m venv .venv
source .venv/bin/activate
python -m pip install .
  2. STEP 02

    모델 없이 실행 확인

    환경을 확인하고 2마디 예제의 MIDI와 JSON을 만듭니다. 이 예제는 설치 확인용 고정 패턴이며 AI 작곡 결과가 아닙니다.

    출력 폴더는 새 이름을 사용하세요. Ollama 미연결 메시지가 있어도 demo는 실행할 수 있습니다.

    TERMINAL · FIRST RUN
    deepchord doctor
deepchord demo --out "$HOME/Music/deepchord-demo"
deepchord validate "$HOME/Music/deepchord-demo/composition.json"
    결과 폴더에서 composition.mid와 composition.json을 확인하세요.
  3. STEP 03

    로컬 모델로 작곡

    Ollama ↗를 별도로 설치·실행하고, 컴퓨터 사양에 맞는 로컬 모델을 준비하세요. ollama list에 나온 모델 이름으로 아래 자리표시자를 바꿉니다.

    모델은 포함되어 있지 않습니다. 생성 결과가 음표 검증을 통과하지 못하면 요청을 조정해 다시 시도하세요.

    TERMINAL · COMPOSE
    ollama list
# YOUR_INSTALLED_LOCAL_MODEL을 설치된 모델 이름으로 바꾸세요.
deepchord compose '따뜻한 C장조 재즈 피아노곡, 마지막은 Cmaj7' \
  --bars 4 --model YOUR_INSTALLED_LOCAL_MODEL
    성공하면 결과 폴더 경로가 출력됩니다. 기본 위치: ~/.local/share/sovereign-music/music/
  4. STEP 04

    Logic에서 고치고 연주

    먼저 위에서 만든 설치 예제를 열어보세요. 실제 작곡 결과를 열 때는 출력된 결과 폴더 경로로 바꾸면 됩니다. 작곡 명령에 --logic을 추가하면 생성 직후 연결합니다.

    현재 Logic 작업을 저장한 뒤 실행하세요. 가져오기 창을 확인하고 악기와 음색을 선택한 후 프로젝트를 저장합니다.

    TERMINAL · LOGIC PRO
    deepchord logic open "$HOME/Music/deepchord-demo"
    MIDI 열기 요청과 실제 가져오기·소리 재생은 별도로 확인합니다. MCP는 파일 열기에 필수가 아닙니다.
