02 / ABSTRACT

초록

음악을 만드는 기술이 보편화될수록,
창작의 주도권을 다시 묻습니다.

Sovereign Music Lab은 음악가의 지식, 로컬 AI, 인간의 연주를 하나의 창작 과정으로 연결하는 프로젝트입니다. 음악 이론 자료를 검색하는 RAG, 검토된 예제로 모델을 조정하는 LoRA, 편집 가능한 MIDI와 Logic Pro 작업 흐름을 함께 탐구합니다.

우리가 지향하는 소버린 음악은 자신의 자료와 도구, 창작 과정을 직접 관리할 수 있는 음악입니다. AI가 제안한 음표는 완성의 시작점입니다. 사람이 고르고, 고치고, 호흡과 강약을 더하며 자신의 연주로 작품을 완성합니다.

원하는 음악을 말로 적어 보세요. DeepChord는 로컬 AI로 짧은 피아노 스케치를 만들고, SovaRoll은 음표와 오디오를 편집하는 작업실입니다. SovaFlow는 선택적으로 두 도구와 피드백을 이어 줍니다.

세 프로그램은 각각 따로 쓸 수 있습니다. 필요한 것부터 시작하세요. 로컬 AI 모델과 Logic Pro는 별도 설치이며, 완성곡을 무인으로 만들어 주는 것은 아닙니다.

01

SOVAROLL / THE WORKSPACE

SovaRoll
내 손으로 편집하는 작업실.

SovaRoll은 컴퓨터에서 실행하고 브라우저로 사용하는 음악 작업 프로그램입니다. 노래의 재료를 트랙에 놓고, 음표를 고치고, 녹음한 소리를 더해 한 곡으로 정리할 수 있습니다. 다른 두 프로젝트나 AI 모델 없이도 시작합니다.

예를 들어 DeepChord가 만든 MIDI를 가져와 멜로디를 바꾸거나, 내가 연주한 오디오를 추가한 뒤 결과를 내보낼 수 있습니다. MIDI는 계속 편집 가능한 음표이고 WAV는 완성된 소리 파일입니다.

01 / CREATE & EDIT

음표와 오디오

피아노롤과 악보 보기에서 MIDI를 편집하고 WAV·AIFF를 가져오거나 녹음합니다. 악보는 MusicXML로 내보낼 수 있습니다.

02 / LISTEN & MIX

듣고 정리하기

재생하며 트랙의 크기와 좌우 위치를 조절하고, 실수는 실행 취소합니다. MIDI와 믹스 WAV를 각각 내보냅니다.

03 / KEEP YOUR WORK

저장과 백업

프로젝트는 내 컴퓨터에 저장합니다. 버전 저장과 백업 ZIP으로 다시 돌아갈 지점을 남길 수 있습니다.

SovaRoll은 개발 중입니다. 현재 재생은 렌더된 오디오 스냅샷 방식이며 저지연 네이티브 오디오와 외부 플러그인 실시간 호스팅은 앞으로의 과제입니다. 설치와 첫 실행 ↓ · 그림 사용 설명서 ↗

02

SOVAFLOW / THE CONNECTOR

SovaFlow
다음 버전으로 이어 주는 도구.

SovaFlow는 작업의 실행 결과와 사람의 의견을 기록하며 다음 시도를 돕습니다. 먼저 앱 없이 내장 예제로 연습하고, 준비되면 DeepChord와 SovaRoll을 선택적으로 연결할 수 있습니다.

예를 들어 DeepChord 예제 MIDI를 SovaRoll로 가져오고 다시 내보낸 뒤, 직접 듣고 점수와 수정 의견을 남길 수 있습니다. 각 단계가 제안됐는지, 프로그램에 적용됐는지, 검증됐는지를 나눠 표시합니다.

처음이라면, 여기서 시작하세요

세 프로그램을 모두 설치할 필요는 없습니다. 음표를 직접 만지고 싶다면 SovaRoll, 작업 흐름을 연습하고 싶다면 SovaFlow, AI 작곡을 해보고 싶다면 DeepChord부터 시작하세요.

용어 한 가지: MIDI는 소리 자체가 아니라 음높이와 길이 같은 연주 정보가 담긴 파일입니다. 들으려면 악기 소리를 내는 프로그램에서 열어야 합니다.

공통 준비: SovaRoll과 SovaFlow는 Node.js 22 이상이 필요합니다. 설치 파일을 내려받아 안내대로 설치하세요. 두 프로그램을 모두 쓴다면 한 번만 설치하면 됩니다. SovaRoll은 Chrome도 준비하세요.

아래는 macOS와 Windows에서 더블클릭으로 시작하는 방법입니다. ZIP은 압축된 폴더입니다. 내려받은 뒤 압축을 먼저 풀고, 안의 폴더를 문서 폴더처럼 계속 사용할 곳으로 옮겨 주세요.

01 / SOVAROLL

음표와 오디오를 직접 편집하기

로컬 AI나 다른 프로젝트 없이 시작할 수 있습니다.

  1. 1. 내려받기SovaRoll 저장소에서 초록색 Code → Download ZIP을 누르고 압축을 풉니다.
  2. 2. 실행하기압축을 푼 폴더에서 Mac은 Start SovaRoll.command, Windows는 Start SovaRoll.bat을 엽니다. Mac에서 처음 차단되면 파일을 오른쪽 클릭하고 열기 → 열기를 선택하세요. Windows 실행 파일은 제공되지만 검증이 적습니다.
  3. 3. 빈 곡에 음악 넣기처음 열리는 곡은 비어 있어 바로 재생되지 않습니다. 가져오기 → 파일 선택으로 MIDI 파일을 불러오거나, 아래 설명서에 따라 MIDI 트랙·클립과 음표를 먼저 만드세요. 화면이 안 열리면 Chrome 주소창에 http://127.0.0.1:4317을 입력하세요. 함께 열린 터미널 창은 작업하는 동안 열어 둡니다.
  4. 4. 재생하고 저장하기음악을 넣은 뒤 스페이스바로 재생·정지하고 피아노롤에서 음표를 고칠 수 있습니다. 저장 후 MIDI 또는 믹스 WAV로 내보내세요. 작업을 마치면 재생을 멈추고 터미널 창을 닫습니다.

02 / SOVAFLOW

결과와 피드백으로 다음 버전 만들기

먼저 다른 프로그램 없이 연습해 보세요.

  1. 1. 내려받고 실행하기SovaFlow 저장소에서 Code → Download ZIP을 누르고 압축을 푼 뒤, Mac은 Start SovaFlow.command, Windows는 Start SovaFlow.bat을 엽니다. Mac에서 처음 차단되면 오른쪽 클릭 후 열기 → 열기를 선택하세요.
  2. 2. 내장 예제 실행하기터미널 메뉴가 열리면 숫자 2를 입력하고 Enter를 누릅니다. AI나 다른 앱 없이 합성 예제 MIDI가 만들어집니다. 화면에 나온 Run: 폴더 안의 artifacts/compose/synthetic-sketch.mid가 결과입니다.
  3. 3. 결과를 듣고 기록하기결과 MIDI를 SovaRoll이나 MIDI를 재생할 수 있는 프로그램에서 열어 들어 보세요. 메뉴 4에서 기록을 보고, 5에서 점수와 의견을 남깁니다. 실제로 들었을 때만 청취 질문에 y로 답하세요.
  4. 4. 이어가기메뉴 6은 조건이 허용할 때 피드백 기록을 넘겨 다음 실행을 시작합니다. 내장 합성 예제는 연습용 고정 패턴이라 피드백에 따라 음표가 바뀌지는 않습니다. 0은 종료입니다. DeepChord와 SovaRoll을 연결할 때는 먼저 둘을 설치하고 SovaRoll을 실행한 뒤 아래 안내를 따르세요.

두 프로그램 연결: 메뉴 3은 DeepChord의 고정 demo를 SovaRoll로 보내는 예제입니다. 기본적으로 SovaRoll의 4317 포트와 터미널에서 실행 가능한 deepchord를 찾습니다. DeepChord를 아래 가상 환경에 설치했다면 그 환경이 활성화된 터미널에서 SovaFlow의 Start SovaFlow.command를 끌어다 놓고 Enter를 눌러 실행하세요. 메뉴 3의 미리 보기 결과를 확인하고 실제 적용 질문에 y를 입력합니다.

다른 포트나 DeepChord 실행 파일을 쓰려면 SOVAFLOW_SOVAROLL_URL과 SOVAFLOW_DEEPCHORD 환경 변수를 설정할 수 있습니다. 작업 파일에서 값을 직접 지정했다면 그 값이 환경 변수보다 우선합니다. Windows나 자세한 설정은 전체 연결 안내 ↗를 참고하세요.

01

PHILOSOPHY

음악의 주도권은
만드는 사람에게.

작곡가는 결과물뿐 아니라 그 결과에 도달하는 과정도 다룰 수 있어야 합니다. 어떤 자료를 참고했는지, 어떤 모델을 썼는지, 어느 음표를 바꿨는지 확인하고 선택할 수 있는 환경을 만듭니다.

개인에게는 자신만의 작곡 작업실을, 개발자에게는 확장할 수 있는 도구를, 음악가에게는 해석하고 연주할 수 있는 재료를 제공합니다. 이 세 가지 방향이 하나의 연구실 안에서 만납니다.

01 / OWN YOUR PROCESS

과정을 보유합니다

작곡 요청, 참고 근거, 음표와 수정 기록을 로컬 작업 공간에 남깁니다.

02 / KEEP IT EDITABLE

수정할 여지를 남깁니다

MIDI 음표와 페달 데이터를 보존해 사람이 직접 편곡하고 해석합니다.

03 / PLAY IT YOUR WAY

연주로 완성합니다

같은 음표에서도 다른 호흡과 시간이 생깁니다. 마지막 선택은 연주자의 몫입니다.

04

FROM INSTALL TO FIRST NOTES

DeepChord를 설치하고,
첫 스케치를 만들어 보세요.

이 부분은 DeepChord 설치 안내입니다. Mac에서는 응용 프로그램 → 유틸리티 → 터미널을 열고 아래 명령을 순서대로 입력한 뒤 각 줄마다 Enter를 누르세요. Git과 Python 3.11 이상이 필요합니다. 아래 예시는 macOS·Linux 기준이며, Windows PowerShell 설치 방법은 별도로 안내합니다.

Logic 연결: macOS + Logic Pro · MLX: Apple Silicon Mac
선택적 Transformers/PEFT 학습: 호환 HF 모델·환경 필요
기본 설치 확인에는 모델이나 음악 교재가 필요하지 않습니다.

  1. STEP 01

    내 컴퓨터에 설치

    Git은 프로그램을 내려받는 도구이고 Python은 DeepChord 실행에 필요합니다. 아래 명령은 코드를 내려받고 독립된 실행 환경을 만듭니다. 이후 명령은 같은 터미널 창에서 실행하세요. 새 창을 열었다면 DeepChord 폴더로 이동해 source .venv/bin/activate를 다시 실행하세요.

    TERMINAL · INSTALL
    git clone https://github.com/Sovereign-Music-Lab/DeepChord.git
cd DeepChord
python3 -m venv .venv
source .venv/bin/activate
python -m pip install .
  2. STEP 02

    모델 없이 실행 확인

    환경을 확인하고 2마디 예제의 MIDI와 JSON을 만듭니다. 이 예제는 설치 확인용 고정 패턴이며 AI 작곡 결과가 아닙니다.

    출력 폴더는 새 이름을 사용하세요. Ollama 미연결 메시지가 있어도 demo는 실행할 수 있습니다.

    TERMINAL · FIRST RUN
    deepchord doctor
deepchord demo --out "$HOME/Music/deepchord-demo"
deepchord validate "$HOME/Music/deepchord-demo/composition.json"
    홈 폴더의 Music/deepchord-demo에서 composition.mid와 composition.json을 확인하세요. MIDI는 SovaRoll 같은 프로그램에서 열어 들을 수 있습니다.
  3. STEP 03

    로컬 모델로 작곡

    Ollama ↗를 별도로 설치·실행하고, 컴퓨터 사양에 맞는 로컬 모델을 준비하세요. ollama list에 나온 모델 이름으로 아래 자리표시자를 바꿉니다.

    모델은 포함되어 있지 않습니다. 로컬 모델이 잘못된 음표나 화성을 내면 자동 재시도 후에도 작곡이 실패할 수 있습니다. 이때 결과 MIDI는 만들어지지 않습니다. 요청을 조정해 다시 시도하세요.

    TERMINAL · COMPOSE
    ollama list
# YOUR_INSTALLED_LOCAL_MODEL을 설치된 모델 이름으로 바꾸세요.
deepchord session --name my-song --bars 4 \
  --model YOUR_INSTALLED_LOCAL_MODEL
    composer>가 보이면 “따뜻한 C장조 피아노 선율을 만들어줘”처럼 입력하고 Enter를 누르세요. 결과가 나오면 “반주는 더 비워줘”처럼 다시 요청할 수 있습니다. /explain은 곡 설명, /quit은 종료입니다. 같은 세션 이름으로 다시 이어갈 수 있습니다. 결과는 기본적으로 홈 폴더의 .local/share/sovereign-music/에 저장됩니다.
  4. STEP 04

    Logic에서 고치고 연주

    먼저 위에서 만든 설치 예제를 열어보세요. 실제 작곡 결과를 열 때는 출력된 결과 폴더 경로로 바꾸면 됩니다. 작곡 명령에 --logic을 추가하면 생성 직후 연결합니다.

    현재 Logic 작업을 저장한 뒤 실행하세요. 가져오기 창을 확인하고 악기와 음색을 선택한 후 프로젝트를 저장합니다.

    TERMINAL · LOGIC PRO
    deepchord logic open "$HOME/Music/deepchord-demo"
    MIDI 열기 요청과 실제 가져오기·소리 재생은 별도로 확인합니다. MCP는 파일 열기에 필수가 아닙니다.
