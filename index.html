02 / ABSTRACT

초록

음악을 만드는 기술이 보편화될수록,
창작의 주도권을 다시 묻습니다.

Sovereign Music Lab은 음악가의 지식, 로컬 AI, 인간의 연주를 하나의 창작 과정으로 연결하는 프로젝트입니다. 음악 이론 자료를 검색하는 RAG, 검토된 예제로 모델을 조정하는 LoRA, 편집 가능한 MIDI와 Logic Pro 작업 흐름을 함께 탐구합니다.

우리가 지향하는 소버린 음악은 자신의 자료와 도구, 창작 과정을 직접 관리할 수 있는 음악입니다. AI가 제안한 음표는 완성의 시작점입니다. 사람이 고르고, 고치고, 호흡과 강약을 더하며 자신의 연주로 작품을 완성합니다.

01

PHILOSOPHY

음악의 주도권은
만드는 사람에게.

작곡가는 결과물뿐 아니라 그 결과에 도달하는 과정도 다룰 수 있어야 합니다. 어떤 자료를 참고했는지, 어떤 모델을 썼는지, 어느 음표를 바꿨는지 확인하고 선택할 수 있는 환경을 만듭니다.

개인에게는 자신만의 작곡 작업실을, 개발자에게는 확장할 수 있는 도구를, 음악가에게는 해석하고 연주할 수 있는 재료를 제공합니다. 이 세 가지 방향이 하나의 연구실 안에서 만납니다.

01 / OWN YOUR PROCESS

과정을 보유합니다

작곡 요청, 참고 근거, 음표와 수정 기록을 로컬 작업 공간에 남깁니다.

02 / KEEP IT EDITABLE

수정할 여지를 남깁니다

MIDI 음표와 페달 데이터를 보존해 사람이 직접 편곡하고 해석합니다.

03 / PLAY IT YOUR WAY

연주로 완성합니다

같은 음표에서도 다른 호흡과 시간이 생깁니다. 마지막 선택은 연주자의 몫입니다.

02

THE CREATIVE LOOP

지식은 음표가 되고,
음표는 연주가 됩니다.

검색과 학습, 작곡과 연주는 서로 다른 역할을 맡습니다. 각 단계를 구분하고 검토하며, 사람의 피드백이 다음 실험의 출발점이 되도록 설계합니다.

  1. 01

    Knowledge

    인간이 쌓은 지식

    사용자가 보유한 자료에서 필요한 음악 이론과 근거를 검색합니다.

    RAG · OPTIONAL
  2. 02

    Intelligence

    로컬 모델의 제안

    모델이 음표를 구성합니다. LoRA는 별도로 검토한 예제를 통한 추가 학습입니다.

    LOCAL LLM + LoRA
  3. 03

    Composition

    편집 가능한 음악

    음표·박자·일부 화성 조건을 검사하고, MIDI를 Logic으로 전달합니다.

    MIDI → LOGIC PRO
  4. 04

    Performance

    사람의 해석과 연주

    직접 고치고 연주합니다. 평가는 기록하며, 다음 학습에는 별도 검토를 거칩니다.

    HUMAN FEEDBACK

↶ 다시 듣고, 다시 고치고, 다음 곡으로.

03

WORK IN PROGRESS

작동하는 첫 도구.
열려 있는 다음 질문.

현재 버전은 로컬 피아노 스케치를 위한 실험용 도구입니다. 기능이 실행되는지 확인하는 일과 음악이 좋은지 평가하는 일을 구분합니다.

로컬 작곡과 MIDI

로컬 모델 호출, 선택적 RAG, 음표 검증, MIDI 출력과 피드백 기록.

구현
Logic 연결

MIDI 파일 열기와 선택적 MCP 상태 확인. 대화상자·음색·저장은 사용자의 확인이 필요합니다.

부분 자동화
MLX LoRA

데이터 분리, 학습, 테스트 손실 평가, 어댑터 재사용. 소형 모델로 실행 경로를 확인했습니다.

기능 검증
음악적 평가와 확장

실제 연주 평가, 청취에 기반한 수정, 더 다양한 편성과 장기적인 학습 실험.

다음 연구

학습 실행이나 수치 검증만으로 작곡 품질 향상을 주장하지 않습니다. 특정 GPT 모델에 준하는 작곡 능력을 검증한 프로젝트도 아닙니다.

04

OPEN TOOLS, PRIVATE MATERIALS

도구는 함께 나누고,
자료는 각자의 손에.

누구나 자신의 환경에서 실험을 시작할 수 있도록 도구와 사용 방법을 정리합니다. 개인의 자료와 음악까지 공개해야 참여할 수 있는 구조를 요구하지 않습니다.

SHARE

공개 대상으로 검토한 코드·문서·테스트

KEEP LOCAL

원본 PDF·RAG 데이터·모델 가중치·학습 데이터·개인 음악과 작업 기록

이 페이지에는 프로젝트 소개만 담겨 있습니다. 개인 교재, 모델 파일, 학습 데이터는 포함하지 않습니다.
