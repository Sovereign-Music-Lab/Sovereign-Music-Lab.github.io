02 / ABSTRACT

Abstract

As music technology reaches more people,
creative agency deserves another look.

Sovereign Music Lab connects musical knowledge, local AI and human performance in one creative process. We explore RAG for retrieving theory, LoRA for adapting models with reviewed examples, and workflows built around editable MIDI and Logic Pro.

For us, sovereign music means being able to manage your own materials, tools and creative process. Notes proposed by AI are a starting point. A person selects, revises and adds phrasing and dynamics, completing the work through performance.

THREE TOOLS / START HERE

Three tools for making music

Make an idea.
Shape it yourself.
Listen and try again.

Describe the music you want. DeepChord uses local AI to suggest a short piano sketch. SovaRoll is your workspace for editing notes and audio. SovaFlow can connect the tools and keep track of your feedback.

Each program works on its own, so start with the one you need. A local AI model and Logic Pro are separate installations. The programs do not automatically produce a finished song for you.

01 / COMPOSITION IDEASDeepChord ↗

Describe an idea to create a 1–16 bar piano sketch and save it as MIDI. Composition needs a local model; a fixed example checks installation without one.

02 / EDITING WORKSPACESovaRoll ↗

Edit MIDI and audio in your browser, view a score, and export MIDI, MusicXML or audio. Requires Node.js 22+ and remains in development.

03 / CONNECTION & FEEDBACKSovaFlow ↗

Run jobs, record results and feedback, and continue to another version. With Node.js 22+, practise using the built-in example without other apps.

START HERE / FIRST STEPS

New here? Start with one tool.

You do not need to install all three. Choose SovaRoll to edit notes, SovaFlow to practise the feedback loop, or DeepChord to try AI composition.

One useful term: MIDI is a file of performance information such as note pitch and length, not sound itself. Open it in a program that plays an instrument to hear it.

Before you begin: SovaRoll and SovaFlow need Node.js 22 or newer. Download its installer and follow the prompts; install it only once if you use both. For SovaRoll, also have Chrome ready.

The steps below use double-click starters on macOS and Windows. A ZIP is a compressed folder: extract it first, then move the resulting folder somewhere permanent, such as Documents.

01 / SOVAROLL

Edit notes and audio

Start without local AI or the other projects.

  1. 1. DownloadOpen the SovaRoll repository, choose the green Code → Download ZIP button, and extract the download.
  2. 2. StartIn the extracted folder open Start SovaRoll.command on Mac or Start SovaRoll.bat on Windows. If macOS blocks the first launch, right-click the file and choose Open → Open. The Windows starter is provided but less thoroughly tested.
  3. 3. Explore your first songWhen the page opens in your browser, press Space to play or stop. If it does not open, type http://127.0.0.1:4317 into Chrome. Keep the accompanying terminal window open while working.
  4. 4. Edit and saveUse + Track and the piano roll to add notes, or Import to open MIDI. Save, then export MIDI or a WAV mix. When finished, stop playback and close the terminal window.

02 / SOVAFLOW

Use results and feedback for the next version

Practise first without other programs.

  1. 1. Download and startOpen the SovaFlow repository, choose Code → Download ZIP and extract it. Open Start SovaFlow.command on Mac or Start SovaFlow.bat on Windows. If macOS blocks the first launch, right-click and choose Open → Open.
  2. 2. Run the built-in exampleIn the terminal menu, type 2 and press Enter. This creates a synthetic example MIDI without AI or other apps. Check the displayed run result and path.
  3. 3. Listen and record feedbackOpen the resulting MIDI in SovaRoll or a MIDI player. Choose 4 to see runs and 5 to give a rating and note. Answer y to the listening question only if you actually listened.
  4. 4. ContinueMenu 6 starts the next run from feedback when the stop rules permit it; 0 quits. To connect DeepChord and SovaRoll, install both and start SovaRoll first, then follow the connection guide.

A SOVEREIGN MUSIC LAB PROJECT

DeepChord.

Take the first notes from local AI.

DeepChord on GitHub ↗Installation guide ↓

DeepChord is a piano composition toolkit connecting personal musical knowledge with local language models. It turns a natural-language request into symbolic notes, validates them and exports editable MIDI.

Public theory RAG and a computed chord dictionary are included. Add private sources or LoRA when useful, then keep revising through the human’s next request.

PYTHON 3.11+APACHE 2.0LOCAL-FIRST
  1. RAG · LoRAPersonal knowledge and training
  2. Local LLM1–16 bars · keep revising
  3. Editable MIDIValidate and export notes
  4. Logic Pro + MCPHuman editing and performance

The current Logic integration opens MIDI files and optionally reads status through MCP. You select instruments, save the project and perform the music.

PUBLIC FOUNDATIONS / 0.3

General harmony is expressed in new explanations and formulas. No textbook prose, index structure, scores or OCR is distributed. Thirty-two formulas across twelve roots compute the dictionary; the same public sources reproduce RAG and LoRA examples.

04

FROM INSTALL TO FIRST NOTES

Install the toolkit.
Start with a few notes.

This section installs DeepChord. On a Mac, open Applications → Utilities → Terminal, enter the commands below in order, and press Enter after each line. You need Git and Python 3.11 or later. The examples use macOS/Linux shells; follow the separate Windows PowerShell instructions on Windows.

Logic: macOS + Logic Pro · MLX: Apple Silicon Mac
Optional Transformers/PEFT training requires a compatible HF model and environment
The installation check needs no model or music textbook.

  1. STEP 01

    Install on your computer

    Git downloads the program; Python runs it. These commands download the code and create an isolated environment. Use the same terminal for the following steps. If you open a new terminal, enter the DeepChord folder and run source .venv/bin/activate again.

    TERMINAL · INSTALL
    git clone https://github.com/Sovereign-Music-Lab/DeepChord.git
cd DeepChord
python3 -m venv .venv
source .venv/bin/activate
python -m pip install .
  2. STEP 02

    Try it without a model

    Check your environment and create a two-bar MIDI and JSON example. This is a deterministic installation fixture, not an AI composition.

    Choose a new output directory. The demo still works if doctor reports that Ollama is unavailable.

    TERMINAL · FIRST RUN
    deepchord doctor
deepchord demo --out "$HOME/Music/deepchord-demo"
deepchord validate "$HOME/Music/deepchord-demo/composition.json"
    Find composition.mid and composition.json in Music/deepchord-demo inside your home folder. Open the MIDI in a program such as SovaRoll to hear it.
  3. STEP 03

    Compose with a local model

    Ollama ↗ must be installed and running separately, with a local model that fits your hardware. Run ollama list and replace the placeholder below with an installed model name.

    No model is bundled. If generated notes fail validation, adjust your request and try again.

    TERMINAL · COMPOSE
    ollama list
# Replace YOUR_INSTALLED_LOCAL_MODEL with an installed model name.
deepchord session --name my-song --bars 4 \
  --model YOUR_INSTALLED_LOCAL_MODEL
    When composer> appears, type a request such as “Create a warm piano melody in C major” and press Enter. After the result, ask for a change such as “Make the accompaniment sparser.” Use /explain for the explanation and /quit to exit; resume with the same session name. Results are saved by default in .local/share/sovereign-music/ in your home folder.
  4. STEP 04

    Edit and play in Logic

    Start by opening the installation example above. For a generated composition, replace the path with its output directory. Add --logic to a compose command to open the result immediately.

    Save your current Logic work first. Review the import dialogs, select instruments and sounds, then save the project.

    TERMINAL · LOGIC PRO
    deepchord logic open "$HOME/Music/deepchord-demo"
    An accepted open request does not verify import or audible playback. MCP is optional for opening the file.
